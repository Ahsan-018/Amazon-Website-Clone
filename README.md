# Amazon Website Clone

A static front-end clone of the Amazon homepage built using pure **HTML5** and **CSS3**.

## Features
- **Navigation Bar**: Includes Amazon logo, delivery location selector, search bar with category filter, sign-in options, returns & orders, and cart icon.
- **Sub-Navigation Panel**: Quick links for Deals, Customer Service, Registry, Gift Cards, and Sell.
- **Hero Section**: Promotional banner layout.
- **Product Category Grid**: Multi-column product cards styled with CSS Flexbox/Grid.
- **Footer**: Multi-level Amazon footer with back-to-top button, informational links, and copyright section.

## Technologies Used
- HTML5
- CSS3
- Font Awesome (for icons)
